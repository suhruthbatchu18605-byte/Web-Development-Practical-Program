Inline, Internal, and External CSS

Demonstrates the three methods of applying CSS styles: inline style attributes, internal <style> blocks, and external linked .css files, highlighting precedence rules.

Demonstration Output

1. Internal CSS (defined in document <style> element)
2. Inline CSS (style="..." attribute directly on the tag)
3. External CSS (loaded from assets/css/program.css)
