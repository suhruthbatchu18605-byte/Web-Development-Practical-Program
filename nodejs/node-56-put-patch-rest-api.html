PUT and PATCH REST API Endpoints

Compares full resource replacement (PUT) versus partial attribute update (PATCH).

📄 Node.js Server Code (NODE-56)

app.put('/api/v1/students/:id', (req, res) => res.json({ type: 'PUT full replace', data: req.body })); app.patch('/api/v1/students/:id', (req, res) => res.json({ type: 'PATCH partial update', data: req.body }));

Run natively via terminal: node nodejs/node_56.js or test using the live in-browser API console below.
