## How to Run
1. **Direct In-Browser Mode (No Setup Required):**
   - Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
   - Navigate to **HTML**, **CSS**, **JavaScript**, or **Node.js Backend**.
   - Every Node.js experiment includes an interactive live runner and API console to execute requests and observe responses directly in the browser!

2. **Live Node.js Server Mode:**
   - In terminal, navigate to the project directory:
     ```bash
     node server.js
     ```
   - Open `http://localhost:5000` in your web browser.
   - The entire website will be served live with real backend API endpoints (`/api/students`, `/api/products`, `/api/auth/login`).
